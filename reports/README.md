# Reportes de estancia — AbogadoSoft (Backend)

Reportes de actividades orientados a la capa backend del proyecto, con estructura y redacción alineados a los formatos institucionales (ejemplos en `estancias2/`).

## Contenido

- **REPORTE_01_Backend_AbogadoSoft.md** — Primer periodo: revisión de documentación, modelo de datos (Prisma/PostgreSQL), configuración del backend, estructura de rutas API, autenticación con Supabase y control de versiones.

## Uso

1. Completar en el documento: REPORTE NO., INTERVALO DE FECHAS y, si aplica, marcar el tipo de práctica (EI / EII / ESTADÍA).
2. En la sección B (Evidencias fotográficas), añadir capturas de pantalla o enlaces a evidencias.
3. Para entregar en Word: copiar el contenido al formato institucional (Anexo I) y ajustar formato/tablas según la plantilla de la UPQROO.

## Estilo de redacción (referencia)

- Primera persona: "Revisé", "Definí", "Implementé", "Configuré".
- Actividades con título numerado y párrafos descriptivos.
- Uso de listas y tablas para módulos, rutas y entidades.
- Bloques de código cuando aportan claridad (configuración, estructura de carpetas).
- Secciones finales: Evidencias fotográficas y Etapas cumplidas (lista numerada).
